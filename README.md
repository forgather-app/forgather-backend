## 서비스 개요

> 포게더는 '작가와 방문객에 연결되는 공간 서비스'에요.

시간과 공간이 부족해 전시 공간을 꾸미지 못하는 작가들의 문제에 주목했어요.  
<br/>

## 주요 기능

- 스페이스를 생성해 개인 전시 공간을 마련할 수 있어요.  
- 링크와 QR 코드로 언제 어디서든 쉽게 공유할 수 있어요.  
- 전시 작품에 대한 소개를 작성할 수 있어요.  
- 스페이스를 통해 방문객에게 메세지를 전달할 수 있어요.
- 방문객들로부터 방명록을 모아볼 수 있어요.
<br/>

## 디자인 시스템

Figma에서 포게더의 자세한 디자인 시스템을 확인할 수 있어요.

[🧑🏻‍🎨️ Figma Design System](https://www.figma.com/design/fboYAj0maxr7EtzTrK3V3M/ForGather-Design-System?node-id=0-1&p=f&t=k8AAJLZRQIZxjzGB-0)

포게더에서 개인 공간은 **스페이스(Space)** 라고 불러요.  
나만의 공간인 스페이스, 우주에 있는 느낌을 주기 위해 신비로운 보라색과 형광 연두색을 사용했어요.
